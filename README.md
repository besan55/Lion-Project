*قالب ليون Leon Template

نبذة عن المشروع

مشروع Leon هو صفحة ويب بسيطة تهدف إلى عرض نموذج لموقع وكالة إبداعية، حيث تقدم الصفحة نبذة عن الخدمات والأعمال والمميزات التي توفرها الوكالة، بالإضافة إلى معلومات التواصل.

تم إنشاء الصفحة باستخدام لغة HTML لتنظيم محتوى الموقع وتقسيمه إلى أقسام واضحة ومنظمة.

## شرح الكود

تم تقسيم الموقع إلى عدة أقسام رئيسية:

1. **Header**: يحتوي على شعار الموقع وقائمة التنقل (Navbar)
2. **Landing Section**: القسم الترحيبي الأول مع عنوان رئيسي وصورة خلفية
3. **Features**: قسم يعرض 3 مميزات للوكالة مع أيقونات
4. **Services**: قسم الخدمات، يحتوي على 4 خدمات مع وصف لكل خدمة وصورة جانبية
5. **Portfolio**: قسم الأعمال، يعرض 3 مشاريع سابقة مع صورها
6. **About**: قسم نبذة عن الوكالة مع صورة ونص تعريفي
7. **Contact**: قسم التواصل يحتوي على الإيميل وروابط السوشال ميديا
8. **Footer**: تذييل الصفحة مع حقوق النشر
